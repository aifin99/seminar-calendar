セミナー登録

チェックすると場所に「ZOOM」が入り、カレンダーで青く表示されます
会場なら住所（地図が開けます）、ZOOM なら参加用の URL
今のチラシはそのまま残ります。新しい画像を選ぶと差し替えます
JPEG / PNG の画像。PDF は画像に書き出してから選んでください
本当に削除しますか？ カレンダーから消えます（申込の記録とチラシのファイルは残ります）。

使い方

  1. 1カレンダーで、申し込みたいセミナーを押します。

  2. 2詳細ページが開きます。チラシを確認します。

  3. 3「所属チーム」を選び、「参加者名」を入れて、「申し込む」を押します。会員以外の方は「ゲスト（会員以外の方）」を選び、「紹介者名」も入れてください。

  4. 4「申し込みました」と出て、「参加予定」の一覧に名前が出れば完了です。

  • 同じ名前では2回申し込めません。
  • 開催日が過ぎたセミナーは「終了」と出て、申し込めません。
  • 申込を取り消すときは、登録を担当する方に伝えてください。

登録を担当する方向けです。合言葉が必要です。登録を担当する方は、合言葉を受け取ってください。

  1. 1右上の「☰」（メニュー）を押し、「セミナー登録」を選びます。

  2. 2「日付」「開始時刻」「講師名」は必ず入れます。

  3. 3ZOOM で開催するときは「ZOOM（Web）で開催」にチェックを入れ、「ZOOM の URL」を入れます。会場で開催するときは「場所」と住所を入れます。

  4. 4「所属」でチームを選び、「テーマ」を入れます。

  5. 5「チラシ」で画像を選びます。チラシは後から「編集」で足すこともできます。

  6. 6「合言葉」を入れて「保存」を押します。

  7. 7「登録しました」と出て、登録したセミナーの詳細ページが開けば完了です。

登録を担当する方向けです。合言葉が必要です。登録を担当する方は、合言葉を受け取ってください。

  1. 1セミナーの詳細ページで、右上の「編集」を押します。

  2. 2「セミナー編集」の画面で直し、「合言葉」を入れて「更新する」を押します。

  3. 3消すときは、「合言葉」を入れてから一番下の赤い「このセミナーを削除する」を押し、「本当に削除しますか？」で「削除する」を押します。申込の記録とチラシのファイルは残ります。
